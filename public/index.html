Help & Support

Why "Not configured"?

AI47 GPT does NOT bundle a 5GB model inside the repo. That would be impossible for Vercel/GitHub. The honest flow:

  1. Code is free and open-source (what you deployed)
  2. AI compute is separate: you install ComfyUI locally, or self-host it, or optionally add cloud provider.

If you deploy to Vercel without a local model, it will correctly say: "AI image generation is not configured yet." It does NOT fake an image.

How to enable generation locally

git clone https://github.com/yourname/AI47-GPT
npm install
# Install ComfyUI separately: https://github.com/comfyanonymous/ComfyUI
# Download SDXL model to ComfyUI/models/checkpoints
COMFYUI_URL=http://127.0.0.1:8188 npm start

Vercel deployment with free cloud

For Vercel, you need a cloud inference endpoint (HF Inference API is free tier). Set in Vercel env: OPTIONAL_CLOUD_PROVIDER=true and implement cloudProvider.js with HF API key server-side only.
